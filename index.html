三步快速接入

标准 REST API，任何语言都能调

1

获取 API Key

平台管理端为你的客户端发放 Key，绑定访问策略（QPS / 配额 / 允许接口）。

2

调用识别接口

携带 Authorization: Bearer {apiKey}，图片 multipart 或 Base64 上传，选择识别类型。

3

拿取结构化结果

同步接口直接返回；异步任务轮询状态或接收 Webhook 回调，取结构化 JSON 入库。

# 同步识别一张增值税发票
curl -X POST 'http://your-host:28090/api/v1/doc/recognize?type=VAT_INVOICE' \
  -H "Authorization: Bearer {apiKey}" \
  -F "file=@增值税发票.png"
